# Arrecadômetro

Site estático da campanha de Natal da Corrente do Bem. Não exige instalação, banco de dados ou backend.

## Atualizar o valor arrecadado

1. Abra `config.js`.
2. Troque o número de `valorArrecadado` pelo total atual.
3. Salve e publique novamente na Vercel.

Para que somente Gabrielle possa atualizar, mantenha o projeto da Vercel privado e permita acesso apenas à conta `gabrielle.diasfreitas2013@gmail.com`. Uma tela de login verdadeiramente segura não pode existir somente no frontend; ela exigiria autenticação e backend. Nesta versão, a proteção é o próprio acesso privado ao projeto/deploy.

## Publicar na Vercel

Envie esta pasta para um repositório privado e importe-o na Vercel como projeto estático. Não é necessário comando de build; o diretório de saída é a própria raiz do projeto.
